## 2. In-Class Question & Answer

> **Question from the Teacher:**  
> *What is a variable?*

> **My Answer:**  
> A variable is a placeholder or container for storing data that a program can use or change. The stored data can be of various data types, such as integers (`int`), text/strings (`str`), floating-point numbers (`float`), booleans, and more.
