# Advanced Programming for Data Science

Welcome to the **Advanced Programming for Data Science** repository.

## Repository Structure

This repository is organized into dedicated branches:

- **`main`**: Project overview, setup instructions, and primary documentation.
- **`Course`**: Lecture slides, code examples, notes, and theoretical course materials.
- **`TP`**: Practical work (Travaux Pratiques / lab sessions), assignments, and exercises.

## Getting Started

### Clone the repository
```bash
git clone https://github.com/Korngmeng-Taing/ADV-Programing-For-DS.git
cd ADV-Programing-For-DS
```

### Switching Branches
- To view course materials:
  ```bash
  git checkout Course
  ```
- To view practical exercises (TP):
  ```bash
  git checkout TP
  ```
